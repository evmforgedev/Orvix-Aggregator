OrvixAggregatorBNB Chain AMM V2 Traversal RouterOrvixAggregator is a robust, multi-factory Automated Market Maker (AMM) V2 routing infrastructure designed for the BNB Chain. Developed by ORVIX Labs, it facilitates deterministic path discovery, intelligent quoting, and efficient swap execution across various supported liquidity sources.This contract is optimized for integration by wallets, decentralized applications (dApps), and broader Web3 infrastructure.Deployed ContractsBNB Smart Chain Mainnet: 0x524a8557005ADdf838c3e267ce43b9B7EBfcCfc7BNB Smart Chain Testnet: 0xA4Bf191D53B880cA49F1ceD0C0C840378bdDef42Key FeaturesMulti-Factory Routing: Seamlessly aggregates liquidity from multiple whitelisted AMM V2 factories (e.g., PancakeSwap, ApeSwap).Per-Factory Fee Support: Dynamically adjusts to the specific fee structures of different AMMs (e.g., 0.25%, 0.30%) ensuring K-invariant consistency throughout pool selection, quoting, and execution.Intelligent Path Discovery: Evaluates direct (single-hop) and indirect (multi-hop via common intermediate tokens) routes to find the most optimal execution path.Liquidity Scoring Engine: Ranks pools based on a composite score considering expected output, geometric mean liquidity, and price impact penalties.Price Impact Filtering: Automatically rejects routes that exceed a configured maximum price impact, protecting users from high slippage.Deterministic Route Encoding: Utilizes a compact, gas-efficient 64-byte-per-hop binary format for encoding swap paths.Protocol Fee Split: Supports a configurable protocol fee (taken from the input amount) that can be split between the protocol treasury and an integrating partner.Native BNB Handling: Seamlessly wraps incoming native BNB to WBNB before swaps and unwraps WBNB to BNB upon exit, abstracting the complexity from the user.Circuit Breaker: Includes an emergency pause mechanism to halt all swaps if necessary.Architecture & Workflow1. Quoting (quoteExactInput)The quoting engine iterates through all whitelisted factories, assessing pools for a given token pair.It calculates expected output based on factory-specific fees.It evaluates liquidity depth and estimated price impact.It compares single-hop routes against multi-hop routes (using configured commonTokens).The best route is selected based on the highest composite score and returned along with an encoded binary path.2. Execution (swapExactInput)The execution function takes the encoded path provided by the quote.It decodes the path and rigorously validates route integrity (hop continuity, factory whitelist status, pool existence).Protocol fees are deducted from the input amount upfront.Native BNB is wrapped to WBNB automatically.The swap is executed hop-by-hop using SafeERC20 transfers and direct pair swaps.Finally, the output is verified against the user's amountOutMin slippage tolerance, and WBNB is unwrapped back to BNB if requested.Route Encoding FormatThe aggregator uses a highly optimized binary format to pass routing instructions from the quote to the swap execution function.Format: [version(1 byte)] [hopCount(1 byte)] [RouteHop] × NEach RouteHop occupies exactly 64 bytes:pool (20 bytes)tokenOut (20 bytes)v2FeeNumerator (2 bytes)v2FeeDenominator (2 bytes)factory (20 bytes)Note: The path encoding always uses the WRAPPED_NATIVE address internally, never the zero address.Contract InterfaceMain User FunctionsquoteExactInput(address tokenIn, address tokenOut, uint256 amountIn, address[] calldata factories, uint256 slippageBps): Returns the optimal swap route, expected output, and the encoded path required for execution. Pass address(0) for native BNB.swapExactInput(address tokenIn, address tokenOut, uint256 amountIn, uint256 amountOutMin, address recipient, uint256 deadline, bytes calldata path, address treasury, address integrator): Executes the swap using the encoded path.Diagnostic FunctionsassessPools(address tokenIn, address tokenOut, uint256 amountIn, address[] calldata factories, bool rawMode): Evaluates all available pools for a pair and returns detailed metrics (output, liquidity, score, fail reasons) for diagnostic purposes.maxInputForPool(address tokenIn, address tokenOut, address[] calldata factories, uint256 targetImpactBps): Calculates the maximum input amount possible for a pair while staying under a target price impact threshold.Admin Functions (Owner Only)initialize(address treasury): Activates the contract and sets the default treasury.setFactoryStatus(address factory, bool status) / batchSetFactoryStatus: Manages the whitelist of allowed AMM factories.setFactoryFee(address factory, uint16 feeNumerator, uint16 feeDenominator): Configures the specific swap fee for a given factory.setCommonTokens(address[] calldata tokens): Sets intermediate tokens used for multi-hop discovery.setProtocolFeeRate(uint256 newRate): Adjusts the protocol fee (max 1%).setCircuitBreaker(bool active): Pauses all swap activity.Installation and CompilationThis contract is written in Solidity ^0.8.34 and relies on OpenZeppelin contracts.Ensure you have the required dependencies installed (e.g., via Foundry or Hardhat):npm install @openzeppelin/contracts
